# Health Database App Blueprints

This will be the back-up and showcase of this apps progress.

The current version can only run in a python environment. The only information the system is set to handle are two nutrient groups, Vitamin and Minerals. 


Carbs, Proteins, and Fats are under research.

The current target is getting the recommended intake table working while formatting the files to work together. 

The next target is getting a large section of food files finished to be searchable, and to show what the "current searchable items".
